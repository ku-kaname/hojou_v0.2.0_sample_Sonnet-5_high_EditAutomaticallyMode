# 実行環境整備

## スコープ

- `要件定義書/フォルダ構成_v1.0.0.md`・`要件定義書/技術スタック_v1.0.0.md`に基づき、フロントエンド・バックエンド・DBを起動するための実行環境一式を整備する。
- 対象：`docker-compose.yml`・`.env.example`・`backend/Dockerfile`・`backend/pyproject.toml`・`backend/alembic.ini`・`backend/migrations/`（初期マイグレーション）・`frontend/Dockerfile`・`frontend/nginx.conf`・`frontend/package.json`・`frontend/tsconfig.json`・`frontend/vite.config.ts`・`frontend/index.html`・リンター設定（ruff・ESLint/Prettier）・`README.md`。

## アプローチ（案）

- `要件定義書/フォルダ構成_v1.0.0.md`のディレクトリ構成を正として配置する。
- DBはPostgreSQL、バックエンドはFastAPI（Python 3.12以降）、フロントエンドはVite + React + TypeScriptとする。
- Alembicは、DB接続・テーブルモデル実装タスクでテーブルモデルが確定した後に初期マイグレーションを生成する（本タスクでは設定ファイルの整備のみ行い、初期マイグレーション生成は当該タスク内で後続して実施する）。
