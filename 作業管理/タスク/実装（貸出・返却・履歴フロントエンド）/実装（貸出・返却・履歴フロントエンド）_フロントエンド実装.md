# フロントエンド：貸出処理・返却処理・期限超過一覧・履歴閲覧画面実装

## スコープ

- `要件定義書/画面一覧_v1.0.0.md`のS02（ホーム（ダッシュボード）。F13件数表示部分のみ）・S07（申請管理（管理者）。F10・F11部分のみ）・S08（期限超過一覧（管理者）。F13一覧部分）・S11（貸出履歴（管理者）。F17）に対応するReactコンポーネントを、`backend/app/main.py`・`schemas.py`（`設計書/main/貸出・返却・履歴/`に対応する実装済みコード、[実装（貸出・返却・履歴）_バックエンド実装_引継書.md](../../../引継ぎ資料/タスク毎/実装（貸出・返却・履歴）_バックエンド実装_引継書.md)参照）に基づき実装する。
    - S07：既存の`frontend/src/pages/LoanRequestManagePage.tsx`へ、承認済み行の「貸出処理」ボタン（`PATCH /loan-requests/{id}/lend`、リクエストボディなし）、貸出中行の「返却処理」ボタン＋パネル（任意の状態メモを入力し`PATCH /loan-requests/{id}/return`を呼ぶ）を追加する。既存の「別バックログで追加予定」の注記を解消する。
    - S02：既存の`frontend/src/pages/HomePage.tsx`へ、管理者向けの期限超過件数ウィジェット（`GET /loan-requests?scope=overdue`の件数を表示し、S08画面へのリンクを設置）を追加する。既存の「別バックログで追加予定」の注記を解消する。
    - S08：新規ページ`frontend/src/pages/OverdueLoanRequestsPage.tsx`として、`GET /loan-requests?scope=overdue`（管理者専用、既に`実装（貸出申請・承認）`バックログで実装済みのエンドポイントを再利用）で期限超過中の貸出一覧を取得し、読み取り専用の一覧表示を行う。
    - S11：新規ページ`frontend/src/pages/LoanHistoryPage.tsx`として、`GET /loan-requests?scope=all&status=...`（状態での絞り込み。既存の`LoanRequestManagePage.tsx`と同じクエリ）で全履歴一覧を表示し、`GET /loan-requests/export`（開始日下限・開始日上限・備品ID・借用者IDでの絞り込み、いずれも任意）でCSVファイルをダウンロードするフォームを設置する。
- `frontend/src/api/client.ts`へ、CSVバイナリダウンロード専用の新規関数`apiGetBlob`を追加する。既存の`request<T>`（内部関数）は常に`response.json()`を呼ぶためCSV（`text/csv`）レスポンスの取得に転用できず、`Authorization`ヘッダー付与・`Blob`取得・`Content-Disposition`ヘッダーからのファイル名抽出を行う専用関数が必要なため。
- `frontend/src/types/common.ts`へ、`LoanRequestReturnRequest`（`return_note?: string | null`）を追加する。
- `frontend/src/App.tsx`へ、`/loan-requests/overdue`（S08、`AdminRoute`）・`/loan-requests/history`（S11、`AdminRoute`）のルートを追加する。
- `frontend/src/components/Header.tsx`へ、管理者向けの「期限超過一覧」「貸出履歴」ナビゲーションリンクを追加する。
