# 成果物のv1.0.0への更新

## スコープ

- 初回開発であり、v1.0.0未到達の成果物（要件定義書・設計書・単体テスト仕様書・結合テスト仕様書）を、`運用ルール/開発ルール/バージョン管理ルール.md`「プロジェクト完了（初回開発、v1.0.0未到達の場合のみ）」に従い、現在のバージョンをv1.0.0にする（ファイル名のリネーム）。
- これは成果物のバージョンの更新であり、システムのバージョン（gitタグ`v1.0.0`）の付与は本タスクの対象外（v1.0.0公開時に別途行う）。
