| 指摘区分 | 内容 |
|---|---|
| 誤記 | 誤字、脱字、項番誤り |
| 仕様誤り | 要件・仕様を満たすため必要な内容に誤りがあった |
| 矛盾 | 成果物間または成果物内に矛盾を含む内容があった |
| 認識誤り | 仕様の内容理解誤りによるミス |
| 設計漏れ | 開発に必要な設計が漏れていた |
| 実装漏れ | 設計に記載があるにもかかわらず、実装されていない |
| テストケース漏れ | 実装コードの条件分岐・仕様に対応するテストケースがテスト仕様書に記載されていない |
| 質問 | 作業担当者に対しての作成意図の質問・確認 |
| 改善提案 | 誤りではないが、より良い設計・実装方法の提案 |
| 確認待ち | 仕様が未確定で判断できない項目 |

| 重要度 | 内容 |
|---|---|
| 高 | 成果物の正しさ・整合性に直接影響し、放置すると後工程や他機能へ波及しうる |
| 中 | 現時点で動作・整合性に支障はないが、放置すると将来的に問題になりうる |
| 低 | 影響範囲が限定的で、放置しても実害が小さい |

| 原因区分 | 内容 |
|---|---|
| 単純ミス | ケアレスミスにより発生したもの |
| 仕様理解不足 | 仕様に対する理解が足りなかったもの |
| 技術力不足 | 技術的な知識不足により発生したもの |
| 変更漏れ | 仕様変更・設計変更に伴う関連箇所への修正反映漏れ |
| 考慮漏れ | 確かめるべきケース・定義・影響範囲を検討していなかったもの |
| 表記ルール違反 | 定められた表記・書き方に従っていない、または成果物内で表記が統一されていないもの |
| 改善 | 誤りではないが、より良い設計・実装のための修正 |
| 回答 | 質問に対する回答など |
