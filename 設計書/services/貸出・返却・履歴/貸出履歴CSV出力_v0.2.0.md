### 処理概要

#### 【目的】
- 管理者が、貸出履歴を期間・備品・借用者で絞り込んでCSVとして出力する（F17）。

#### 【処理概略】
- 入力値の開始日範囲・備品（内部ID）・借用者（ユーザー内部ID）で貸出履歴（状態を問わない全履歴）を検索する。
- 検索結果の各セルについて、先頭が`=`・`+`・`-`・`@`のいずれかであれば、先頭にシングルクォート（`'`）を付与して無害化する（要件定義書/機能要件「ファイル入出力」参照。Excel等でセルを開いた際に数式として実行されることを防ぐ標準的な対策）。
- ヘッダー行と無害化済みの各行からCSV文字列を組み立て、UTF-8 BOM付きでエンコードする（Excelでの文字化けを避けるため）。

## ○処理詳細

### 1. 貸出申請検索一覧取得

- (1) 入力値の条件で貸出履歴を検索する（状態による絞り込みは行わない＝全履歴が対象）。

  **呼出先**

  | 項目 | 論理名 | 物理名 |
  |---|---|---|
  | クラス | - | - |
  | メソッド | 貸出申請検索一覧取得 | search_loan_requests |

  **引数**

  | 引数 | 型 | 必須 | 設定値 | 備考 |
  |---|---|:---:|---|---|
  | データベース | `Session` | ○ | 入力値．データベース | - |
  | 申請者（ユーザー内部ID） | `int \| None` | - | 入力値．借用者（ユーザー内部ID） | - |
  | 状態 | `str \| None` | - | None | 絞り込みなし（全履歴が対象） |
  | 開始日上限（除く） | `date \| None` | - | None | 本処理では使用しない |
  | 返却予定日上限（除く） | `date \| None` | - | None | 本処理では使用しない |
  | 返却予定日一致 | `date \| None` | - | None | 本処理では使用しない |
  | 備品（内部ID） | `int \| None` | - | 入力値．備品（内部ID） | - |
  | 開始日下限（含む） | `date \| None` | - | 入力値．開始日（下限） | - |
  | 開始日上限（含む） | `date \| None` | - | 入力値．開始日（上限） | - |

### 2. CSVヘッダー行の組み立て

- (1) 以下の物理名をカンマ区切りで連結し、ヘッダー行とする。

  | 13 | requested_at |

  | 15 | lent_at |
  | 16 | returned_at |
  | 17 | cancelled_at |

### 3. CSVデータ行の組み立て

- (1) 貸出申請検索一覧取得の結果の各要素について、以下を1件ずつ実施する。

  - ① 対象要素の各項目（2.の列順、内部ID～返却時状態メモ）を、セルの値として取得する。空（null）の項目は空文字列とする。
  - ② 各セルについて、値の先頭1文字が`=`・`+`・`-`・`@`のいずれかであることを確認する。

    - A. 条件に当たる場合、セルの先頭にシングルクォート（`'`）を付与する（無害化）。
    - B. 条件に当たらない場合、本処理をスキップする。

  - ③ 無害化済みの各セルをカンマ区切りで連結し、1行のCSVデータ行とする。

### 4. CSV文字列の組み立て

- (1) 2.のヘッダー行と3.の各データ行を改行で連結し、UTF-8 BOM付きでエンコードする。

  | 論理名 | 設定値 | 備考 |
  |---|---|---|
  | CSV内容 | ヘッダー行 + 改行 + 各データ行（改行区切り） | 対象の履歴が無い場合はヘッダー行のみ |
  | エンコード | UTF-8（BOM付き） | Excelでの文字化けを避けるため |
