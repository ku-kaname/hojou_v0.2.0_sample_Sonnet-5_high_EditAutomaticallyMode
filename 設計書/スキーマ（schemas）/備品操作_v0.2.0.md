## 備品レスポンス
### クラス
|論理名|物理名|継承元|
|---|---|---|
| 備品レスポンス | EquipmentResponse | EquipmentBase |

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| 備品ID | equipment_id | int | - | - | - | - | - | テーブル定義「EQUIPMENT」の内部IDに対応する、API入出力用の物理名 |
| 有効フラグ | active_flag | bool | - | - | - | - | - | - |
| 貸出状況 | loan_status | str | - | - | - | - | - | "貸出可"<br>"貸出中"<br>テーブル制約に基づかない派生値のため、許容値をここに明記する |
| 返却予定日 | due_date | date | - | - | - | - | - | 貸出状況が"貸出中"の場合のみ設定。"貸出可"の場合はnull |
| 作成日時 | created_at | datetime | - | - | - | - | - | - |
| 更新日時 | updated_at | datetime | - | - | - | - | - | - |

備考：
- GET /equipment（一覧）は、本クラスを要素とするリスト（`list[EquipmentResponse]`）を返却する。
- GET /equipment/{equipment_id}（詳細）は、本クラス単体を返却する。
- POST /equipment（登録）のレスポンスは、本クラス単体を返却する。

## 備品一覧取得クエリパラメータ
### 実装方式

- GET /equipmentのクエリパラメータは、Pydanticリクエストスキーマではなく、エンドポイント層（main.py）の個別のQueryパラメータとして受け取る（本項目は参考情報として記載する）。

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| 分類 | category | str | - | - | - | - | - | 完全一致。未指定時は絞り込みなし |
| キーワード | keyword | str | - | - | - | - | - | 備品名の部分一致。未指定時は絞り込みなし |
| 貸出状況 | loan_status | str | - | - | - | - | - | 許容値は備品レスポンス．貸出状況を参照。未指定時は絞り込みなし |
| 無効な備品を含む | include_inactive | bool | - | - | - | - | - | 既定値：false（有効な備品のみ） |

## 備品無効化・再有効化

- PATCH /equipment/{equipment_id}/deactivate・PATCH /equipment/{equipment_id}/activateは、いずれもリクエストボディを持たない。
- レスポンスは、いずれも更新後の備品情報として、備品レスポンス（`EquipmentResponse`）を返却する。
