備考：
- GET /loan-requests（一覧）は、本クラスを要素とするリスト（`list[LoanRequestResponse]`）を返却する。
- GET /loan-requests/{loan_request_id}（詳細）は、本クラス単体を返却する。
- POST /loan-requests（登録）、PATCH .../cancel・approve・reject・admin-cancel（各状態更新）のレスポンスは、いずれも本クラス単体（更新後の貸出申請情報）を返却する。

## 貸出申請一覧取得クエリパラメータ
### 実装方式

- GET /loan-requestsのクエリパラメータは、Pydanticリクエストスキーマではなく、エンドポイント層（main.py）の個別のQueryパラメータとして受け取る（本項目は参考情報として記載する）。

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| 対象範囲 | scope | str | - | - | - | - | - | 既定値："mine"。許容値："mine"（自分の申請のみ。F07）、"all"（全申請。F09、管理者のみ）。一般ユーザーが"all"を指定した場合は権限エラー（403） |
| 状態 | status | str | - | - | - | - | - | 許容値はテーブル定義「LOAN_REQUEST」の状態を参照。未指定時は絞り込みなし |

## 貸出申請承認

- PATCH /loan-requests/{loan_request_id}/approve（F09）は、リクエストボディを持たない。
- レスポンスは、更新後の貸出申請情報として、貸出申請レスポンス（`LoanRequestResponse`）を返却する。
