## 通知レスポンス
### クラス
|論理名|物理名|継承元|
|---|---|---|
| 通知レスポンス | NotificationResponse | BaseModel |

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| 通知ID | notification_id | int | - | - | - | - | - | テーブル定義「NOTIFICATION」の内部IDに対応する、API入出力用の物理名 |
| 種別 | notification_type | str | - | - | - | - | - | 許容値はテーブル定義「NOTIFICATION」の種別を参照 |
| 関連申請（内部ID） | loan_request_id | int | - | - | - | - | - | - |
| 既読フラグ | read_flag | bool | - | - | - | - | - | - |
| 作成日時 | created_at | datetime | - | - | - | - | - | - |

備考：
- 宛先（ユーザー内部ID）は常にログイン中ユーザー自身であるため、レスポンスには含めない。
- GET /notifications（一覧）は、本クラスを要素とするリスト（`list[NotificationResponse]`）を返却する。
- PATCH /notifications/{notification_id}/read（既読化）のレスポンスは、本クラス単体（更新後の通知情報）を返却する。

---

## 通知一覧取得

- GET /notifications（F08）は、クエリパラメータ・リクエストボディを持たない。ログイン中ユーザー宛の通知を全件返却する。

---

## 通知既読化

- PATCH /notifications/{notification_id}/read（F08）は、リクエストボディを持たない。
- レスポンスは、更新後の通知情報として、通知レスポンス（`NotificationResponse`）を返却する。
