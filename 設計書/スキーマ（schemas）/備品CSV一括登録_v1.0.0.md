## 備品CSV一括登録リクエスト
### 実装方式

- POST /equipment/bulk-importは、JSONボディではなくmultipart/form-dataでCSVファイルを受け取る。Pydanticリクエストスキーマは用いず、エンドポイント層（main.py）の独立したFileパラメータとしてファイルを受け取る（本項目は参考情報として記載する）。

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| CSVファイル | file | UploadFile | ○ | - | - | - | 5MB | UTF-8、ヘッダー行あり。列は左から資産番号・備品名・分類・説明・保管場所の順（要件定義書/ファイル入出力参照）。ファイル名はサーバーで使用しない |
