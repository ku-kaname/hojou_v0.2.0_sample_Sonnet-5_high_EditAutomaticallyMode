### 処理概要

#### 【目的】
- 貸出申請を貸出中に更新する（F10）。

#### 【処理概略】
- 状態を"貸出中"に更新し、貸出処理した管理者・貸出日時を記録する。
- 更新後の貸出申請情報を返却する。

## ○処理詳細

### 1. 貸出申請情報更新

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = :status,                    -- 貸出申請情報．状態
    lent_by_user_id = :lent_by_user_id,   -- 貸出申請情報．貸出処理した管理者（ユーザー内部ID）
    lent_at = :now                        -- 貸出申請情報．貸出日時
  WHERE
    id = :loan_request_id;  -- 貸出申請情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | "貸出中" | - |
  | 更新内容 | 貸出処理した管理者（ユーザー内部ID） | ○ | 入力値．貸出処理した管理者（ユーザー内部ID） | - |
  | 更新内容 | 貸出日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | 内部ID | ○ | 入力値．貸出申請（内部ID） | - |
