| メソッド物理名 | return_loan_request |

### 処理概要

#### 【目的】
- 貸出申請を返却済みに更新する（F11）。

#### 【処理概略】
- 状態を"返却済み"に更新し、返却処理した管理者・返却日時・返却時状態メモを記録する。
- 更新後の貸出申請情報を返却する。

## ○処理詳細

### 1. 貸出申請情報更新

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = :status,                          -- 貸出申請情報．状態
    returned_by_user_id = :returned_by_user_id, -- 貸出申請情報．返却処理した管理者（ユーザー内部ID）
    returned_at = :now,                         -- 貸出申請情報．返却日時
    return_note = :return_note                  -- 貸出申請情報．返却時状態メモ
  WHERE
    id = :loan_request_id;  -- 貸出申請情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | "返却済み" | - |
  | 更新内容 | 返却処理した管理者（ユーザー内部ID） | ○ | 入力値．返却処理した管理者（ユーザー内部ID） | - |
  | 更新内容 | 返却日時 | ○ | 入力値．現在日時 | - |
  | 更新内容 | 返却時状態メモ | - | 入力値．返却時状態メモ | - |
  | 検索条件 | 内部ID | ○ | 入力値．貸出申請（内部ID） | - |
