### 処理概要

#### 【目的】
- 備品の有効フラグを更新する（F14の備品無効化・再有効化）。

#### 【処理概略】
- 入力値の内部IDをもとにEQUIPMENTテーブルを検索し、有効フラグを更新する。

## ○処理詳細

### 1. 備品有効化状態更新

- (1) EQUIPMENTテーブルを更新する。

  ```sql
  UPDATE equipment
  SET
    active_flag = :active_flag,  -- 備品情報．有効フラグ
    updated_at = :today            -- 備品情報．更新日時
  WHERE
    id = :equipment_id;  -- 備品情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 有効フラグ | ○ | 入力値．有効フラグ | - |
  | 更新内容 | 更新日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
