### 処理概要

#### 【目的】
- 内部IDをもとに備品情報を1件取得する（F03の備品詳細取得、F14の備品編集・無効化・再有効化、F04の予約状況確認の対象備品確認で使用する）。

#### 【処理概略】
- 入力値の内部IDに一致する備品情報をEQUIPMENTテーブルから取得する（有効フラグによる絞り込みは行わない。無効化済み備品の取得も本メソッドで行い、参照可否の判定は呼出元の責務とする）。
- 取得した備品情報を返却する。

## ○処理詳細

### 1. 備品情報取得

- (1) EQUIPMENTテーブルから取得する。

  ```sql
  SELECT
    id,              -- 備品情報．内部ID
    asset_number,    -- 備品情報．資産番号
    name,            -- 備品情報．備品名
    category,        -- 備品情報．分類
    description,     -- 備品情報．説明
    location,        -- 備品情報．保管場所
    active_flag,     -- 備品情報．有効フラグ
    created_at,       -- 備品情報．作成日時
    updated_at        -- 備品情報．更新日時
  FROM equipment
  WHERE
    id = :equipment_id;  -- 備品情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID～更新日時 | - | - | 上記SELECT列の全項目 |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
