### 処理概要

#### 【目的】
- 備品を分類・キーワード・貸出状態で検索し、各備品の現在の貸出状況（貸出可／貸出中・返却予定日）とともに一覧で取得する（F03）。

#### 【処理概略】
- EQUIPMENTテーブルと、LOAN_REQUESTテーブルのうち状態が「貸出中」の行のみを備品の内部IDで左外部結合し、各備品の現在の貸出状態（結合した行があれば「貸出中」、無ければ「貸出可」）と、貸出中の場合の返却予定日を導出する。
  - 同一備品について「貸出中」の申請は同時に1件のみ存在する業務ルール（要件定義書/機能要件「貸出処理は...貸出中の別申請が存在しない場合のみ行える」）のため、左外部結合によって行が重複することはない。
- 入力値の分類（完全一致）・キーワード（備品名の部分一致）・貸出状態（完全一致）・有効フラグで絞り込む。各絞り込み条件は、入力値が指定されていない場合は条件を適用しない。
- 絞り込んだ結果を、資産番号の昇順で返却する。

## ○処理詳細

### 1. 備品一覧取得

- (1) EQUIPMENTテーブルと、LOAN_REQUESTテーブルの「貸出中」の行を左外部結合して取得する。

  ```sql
  SELECT
    e.id,                   -- 備品情報．内部ID
    e.asset_number,          -- 備品情報．資産番号
    e.name,                  -- 備品情報．備品名
    e.category,              -- 備品情報．分類
    e.description,           -- 備品情報．説明
    e.location,               -- 備品情報．保管場所
    e.active_flag,            -- 備品情報．有効フラグ
    e.created_at,             -- 備品情報．作成日時
    e.updated_at,             -- 備品情報．更新日時
    lr.due_date               -- 貸出申請情報．返却予定日（貸出中の行が無ければNULL）
  FROM equipment AS e
  LEFT JOIN loan_request AS lr
    ON lr.equipment_id = e.id
    AND lr.status = '貸出中'  -- 貸出申請情報．状態
  WHERE
    (:category IS NULL OR e.category = :category)                -- 備品情報．分類
    AND (:keyword IS NULL OR e.name LIKE '%' || :keyword || '%')  -- 備品情報．備品名
    AND (
      :loan_status IS NULL
      OR (:loan_status = '貸出中' AND lr.id IS NOT NULL)
      OR (:loan_status = '貸出可' AND lr.id IS NULL)
    )
    AND (:include_inactive = true OR e.active_flag = true)        -- 備品情報．有効フラグ
  ORDER BY e.asset_number ASC;  -- 備品情報．資産番号
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID～更新日時 | - | - | EQUIPMENTの全項目 |
  | 取得内容 | 返却予定日 | - | - | 貸出中の場合のみ値が入る。貸出可の場合はNULL |
  | 検索条件 | 分類 | - | 入力値．分類 | - |
  | 検索条件 | キーワード | - | 入力値．キーワード | - |
  | 検索条件 | 貸出状態 | - | 入力値．貸出状態 | - |
  | 検索条件 | 有効フラグ | - | 入力値．無効化済み備品を含める | - |
  | ソート条件 | 資産番号 | ○ | 昇順 | - |
