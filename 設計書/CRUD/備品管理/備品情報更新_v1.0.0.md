| メソッド物理名 | update_equipment |

### 処理概要

#### 【目的】
- 備品の資産番号・備品名・分類・説明・保管場所を更新する（F14の備品編集）。

#### 【処理概略】
- 入力値の内部IDをもとにEQUIPMENTテーブルを検索し、資産番号・備品名・分類・説明・保管場所を更新する。
- 更新後の備品情報を返却する。

## ○処理詳細

### 1. 備品情報更新

- (1) EQUIPMENTテーブルを更新する。

  ```sql
  UPDATE equipment
  SET
    asset_number = :asset_number,  -- 備品情報．資産番号
    name = :name,                  -- 備品情報．備品名
    category = :category,          -- 備品情報．分類
    description = :description,    -- 備品情報．説明
    location = :location,          -- 備品情報．保管場所
    updated_at = :today             -- 備品情報．更新日時
  WHERE
    id = :equipment_id;  -- 備品情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 資産番号 | ○ | 入力値．資産番号 | - |
  | 更新内容 | 備品名 | ○ | 入力値．備品名 | - |
  | 更新内容 | 分類 | ○ | 入力値．分類 | - |
  | 更新内容 | 説明 | - | 入力値．説明 | 入力が無い場合は空文字 |
  | 更新内容 | 保管場所 | - | 入力値．保管場所 | 入力が無い場合は空文字 |
  | 更新内容 | 更新日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
