### 処理概要

#### 【目的】
- CSV一括登録（F15）において、検証済みの複数の備品情報を一括でデータベースへ登録する。

#### 【処理概略】
- 入力値（検証済みの備品情報リスト）をもとに、EQUIPMENTテーブルへ全件をまとめて登録する。全件を1つのトランザクションとして登録し、1件でも登録に失敗した場合は全件をロールバックする（要件定義書/ファイル入出力「1行でもエラーがあれば全件登録しない」への対応）。
  - CSVの内容検証（列構成・文字数・資産番号の重複等）は、呼出元（services.py）が本メソッドの呼び出し前に完了させておく。本メソッドは検証済みの登録内容を受け取り、登録処理のみを行う。
- 登録した備品情報のリストを返却する。

## ○処理詳細

### 1. 複数備品情報登録

- (1) EQUIPMENTテーブルへ、入力値の備品登録情報リストの件数分まとめて登録する（1トランザクション）。

  ```sql
  INSERT INTO equipment (
    asset_number,  -- 備品情報．資産番号
    name,          -- 備品情報．備品名
    category,      -- 備品情報．分類
    description,   -- 備品情報．説明
    location,      -- 備品情報．保管場所
    active_flag,   -- 備品情報．有効フラグ
    created_at,     -- 備品情報．作成日時
    updated_at      -- 備品情報．更新日時
  ) VALUES (
    :asset_number,
    :name,
    :category,
    :description,
    :location,
    :active_flag,
    :today,
    :today
  );  -- 入力値．備品登録情報リストの各要素について1件ずつ実行
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 資産番号 | ○ | 入力値．備品登録情報リスト［各要素］．資産番号 | - |
  | 登録内容 | 備品名 | ○ | 入力値．備品登録情報リスト［各要素］．備品名 | - |
  | 登録内容 | 分類 | ○ | 入力値．備品登録情報リスト［各要素］．分類 | - |
  | 登録内容 | 説明 | - | 入力値．備品登録情報リスト［各要素］．説明 | 入力が無い場合は空文字 |
  | 登録内容 | 保管場所 | - | 入力値．備品登録情報リスト［各要素］．保管場所 | 入力が無い場合は空文字 |
  | 登録内容 | 有効フラグ | ○ | true | - |
  | 登録内容 | 作成日時 | ○ | 入力値．現在日時 | - |
  | 登録内容 | 更新日時 | ○ | 入力値．現在日時 | - |
