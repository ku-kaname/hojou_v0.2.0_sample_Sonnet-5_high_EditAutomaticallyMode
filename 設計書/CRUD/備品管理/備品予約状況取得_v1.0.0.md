### 処理概要

#### 【目的】
- 指定した備品について、承認済み・貸出中の申請の期間を取得する（F04。要件定義書/機能一覧「備品ごとに、承認済み・貸出中の期間を確認し、空き期間を把握する」参照）。

#### 【処理概略】
- LOAN_REQUESTテーブルから、入力値の備品内部IDに一致し、状態が「承認済み」または「貸出中」の行を、申請者のUSERテーブルと結合して取得する。
  - 申請者氏名は、要件定義書/機能要件「期間・状態のみ表示（借用者名は管理者のみ）」に対応するため取得するが、レスポンスへ含めるかどうかの判定（呼出元のロール確認）はservices.py側の責務とし、本メソッドは常に取得する。
- 取得した結果を、開始日の昇順で返却する。

## ○処理詳細

### 1. 備品予約状況取得

- (1) LOAN_REQUESTテーブルとUSERテーブルを結合して取得する。

  ```sql
  SELECT
    lr.id,                 -- 貸出申請情報．内部ID
    lr.start_date,          -- 貸出申請情報．開始日
    lr.due_date,             -- 貸出申請情報．返却予定日
    lr.status,               -- 貸出申請情報．状態
    u.name AS applicant_name -- ユーザー情報．氏名（申請者）
  FROM loan_request AS lr
  JOIN user AS u
    ON u.id = lr.applicant_user_id  -- 貸出申請情報．申請者（ユーザー内部ID）
  WHERE
    lr.equipment_id = :equipment_id       -- 貸出申請情報．備品（内部ID）
    AND lr.status IN ('承認済み', '貸出中')  -- 貸出申請情報．状態
  ORDER BY lr.start_date ASC;  -- 貸出申請情報．開始日
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID・開始日・返却予定日・状態・申請者氏名 | - | - | 上記SELECT列の全項目 |
  | 検索条件 | 備品（内部ID） | ○ | 入力値．備品（内部ID） | - |
  | 検索条件 | 状態 | ○ | "承認済み","貸出中" | - |
  | ソート条件 | 開始日 | ○ | 昇順 | - |
