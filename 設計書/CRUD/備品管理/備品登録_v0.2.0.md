| メソッド物理名 | create_equipment |

### 処理概要

#### 【目的】
- 備品情報をデータベースへ新規登録する（F14の備品登録）。

#### 【処理概略】
- 入力値をもとにEQUIPMENTテーブルへレコードを登録する。有効フラグは固定の初期値を設定する。
- 登録した備品情報を返却する。

## ○処理詳細

### 1. 備品情報登録

- (1) EQUIPMENTテーブルへ登録する。

  ```sql
  INSERT INTO equipment (
    asset_number,  -- 備品情報．資産番号
    name,          -- 備品情報．備品名
    category,      -- 備品情報．分類
    description,   -- 備品情報．説明
    location,      -- 備品情報．保管場所
    active_flag,   -- 備品情報．有効フラグ
    created_at,     -- 備品情報．作成日時
    updated_at      -- 備品情報．更新日時
  ) VALUES (
    :asset_number,
    :name,
    :category,
    :description,
    :location,
    :active_flag,
    :today,
    :today
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 資産番号 | ○ | 入力値．資産番号 | - |
  | 登録内容 | 備品名 | ○ | 入力値．備品名 | - |
  | 登録内容 | 分類 | ○ | 入力値．分類 | - |
  | 登録内容 | 説明 | - | 入力値．説明 | 入力が無い場合は空文字 |
  | 登録内容 | 保管場所 | - | 入力値．保管場所 | 入力が無い場合は空文字 |
  | 登録内容 | 有効フラグ | ○ | true | - |
  | 登録内容 | 作成日時 | ○ | 入力値．現在日時 | - |
  | 登録内容 | 更新日時 | ○ | 入力値．現在日時 | - |
