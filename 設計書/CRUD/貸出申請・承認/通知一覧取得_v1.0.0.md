#### 【目的】
- ログイン中ユーザー宛の通知一覧を取得する（F08）。

## ○処理詳細

### 1. 通知一覧取得

- (1) NOTIFICATIONテーブルから宛先（ユーザー内部ID）に一致するレコードを、作成日時の降順で取得する。

  ```sql
  SELECT
    id, recipient_user_id, notification_type, loan_request_id,
    read_flag, created_at
  FROM notification
  WHERE
    recipient_user_id = :recipient_user_id  -- 通知情報．宛先（ユーザー内部ID）
  ORDER BY
    created_at DESC;
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID／宛先（ユーザー内部ID）／種別／関連申請（内部ID）／既読フラグ／作成日時 | - | - | 全列を取得 |
  | 検索条件 | 宛先（ユーザー内部ID） | ○ | 入力値．宛先（ユーザー内部ID） | - |
  | 並び順 | 作成日時 | - | 降順 | - |
