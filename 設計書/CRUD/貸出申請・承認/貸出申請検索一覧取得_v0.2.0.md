### 処理概要

#### 【目的】
- 条件に応じて貸出申請一覧を取得する（F07の自分の申請一覧、F09の全申請一覧、ノーショー自動取消バッチの対象抽出のいずれからも共用する汎用的な検索処理）。

#### 【処理概略】
- 入力値の申請者（ユーザー内部ID）・状態・開始日上限・返却予定日上限で絞り込む。各絞り込み条件は、入力値が指定されていない場合は条件を適用しない。
  - F07（自分の申請一覧）は、申請者（ユーザー内部ID）にログインユーザー自身の内部IDを指定して呼び出す。
  - F09（全申請一覧）は、申請者（ユーザー内部ID）を指定せず、必要に応じて状態のみを指定して呼び出す。
  - ノーショー自動取消バッチは、状態と開始日上限（"申請中"かつ開始日が今日より前）、または状態と返却予定日上限（"承認済み"かつ返却予定日が今日より前）を指定して呼び出す。
- 絞り込んだ結果を、申請日時の降順で返却する。

## ○処理詳細

### 1. 貸出申請検索一覧取得

- (1) LOAN_REQUESTテーブルから取得する。

  ```sql
  SELECT
    id, equipment_id, applicant_user_id, start_date, due_date, purpose,
    status, reject_cancel_reason, approved_rejected_by_user_id, lent_by_user_id,
    returned_by_user_id, cancelled_by_user_id, requested_at, approved_rejected_at,
    lent_at, returned_at, cancelled_at, return_note
  FROM loan_request
  WHERE
    (:applicant_user_id IS NULL OR applicant_user_id = :applicant_user_id)  -- 貸出申請情報．申請者（ユーザー内部ID）
    AND (:status IS NULL OR status = :status)                              -- 貸出申請情報．状態
    AND (:start_date_before IS NULL OR start_date < :start_date_before)    -- 貸出申請情報．開始日
    AND (:due_date_before IS NULL OR due_date < :due_date_before)          -- 貸出申請情報．返却予定日
  ORDER BY requested_at DESC;  -- 貸出申請情報．申請日時
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID～返却時状態メモ | - | - | LOAN_REQUESTの全項目 |
  | 検索条件 | 申請者（ユーザー内部ID） | - | 入力値．申請者（ユーザー内部ID） | - |
  | 検索条件 | 状態 | - | 入力値．状態 | - |
  | 検索条件 | 開始日 | - | 入力値．開始日上限（除く） | - |
  | 検索条件 | 返却予定日 | - | 入力値．返却予定日上限（除く） | - |
  | ソート条件 | 申請日時 | ○ | 降順 | - |
