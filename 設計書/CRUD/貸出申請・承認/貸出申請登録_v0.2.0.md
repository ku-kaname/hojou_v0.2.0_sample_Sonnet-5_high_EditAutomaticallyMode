| メソッド物理名 | create_loan_request |

### 処理概要

#### 【目的】
- 貸出申請情報をデータベースへ新規登録する（F05）。

#### 【処理概略】
- 入力値をもとにLOAN_REQUESTテーブルへレコードを登録する。状態は"申請中"固定とし、申請日時に現在日時を設定する。
- 登録した貸出申請情報を返却する。

## ○処理詳細

### 1. 貸出申請情報登録

- (1) LOAN_REQUESTテーブルへ登録する。

  ```sql
  INSERT INTO loan_request (
    equipment_id,       -- 貸出申請情報．備品（内部ID）
    applicant_user_id,  -- 貸出申請情報．申請者（ユーザー内部ID）
    start_date,         -- 貸出申請情報．開始日
    due_date,           -- 貸出申請情報．返却予定日
    purpose,            -- 貸出申請情報．用途
    status,             -- 貸出申請情報．状態
    requested_at        -- 貸出申請情報．申請日時
  ) VALUES (
    :equipment_id,
    :applicant_user_id,
    :start_date,
    :due_date,
    :purpose,
    :status,
    :today
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 備品（内部ID） | ○ | 入力値．備品（内部ID） | - |
  | 登録内容 | 申請者（ユーザー内部ID） | ○ | 入力値．申請者（ユーザー内部ID） | - |
  | 登録内容 | 開始日 | ○ | 入力値．開始日 | - |
  | 登録内容 | 返却予定日 | ○ | 入力値．返却予定日 | - |
  | 登録内容 | 用途 | ○ | 入力値．用途 | - |
  | 登録内容 | 状態 | ○ | "申請中" | - |
  | 登録内容 | 申請日時 | ○ | 入力値．現在日時 | - |
