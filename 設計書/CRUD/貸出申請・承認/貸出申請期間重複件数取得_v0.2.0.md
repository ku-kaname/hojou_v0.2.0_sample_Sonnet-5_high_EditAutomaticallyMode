### 処理概要

#### 【目的】
- 同一備品について、指定した期間と重複する「承認済み」「貸出中」の貸出申請の件数を取得する（二重貸出の防止。F05の申請時・F09の承認時の両方から使用する。要件定義書/機能要件「同一備品について、状態が『承認済み』『貸出中』の申請の期間が重複する申請は承認できない」参照）。

#### 【処理概略】
- 指定した備品（内部ID）について、状態が「承認済み」または「貸出中」であり、かつ指定した開始日・返却予定日の期間と重複する（両端を含む日単位）貸出申請の件数をLOAN_REQUESTテーブルから取得する。
- 除外対象の貸出申請（内部ID）が指定されている場合、その貸出申請自身は件数に含めない（F09の承認時、承認対象の申請自身を重複対象から除外するために使用する）。
- 取得した件数を返却する。

## ○処理詳細

### 1. 貸出申請期間重複件数取得

- (1) LOAN_REQUESTテーブルから件数を取得する。

  ```sql
  SELECT COUNT(*)
  FROM loan_request
  WHERE
    equipment_id = :equipment_id                                              -- 貸出申請情報．備品（内部ID）
    AND status IN ('承認済み', '貸出中')                                      -- 貸出申請情報．状態
    AND start_date <= :due_date AND due_date >= :start_date                   -- 貸出申請情報．開始日／返却予定日（両端を含む期間重複）
    AND (:exclude_loan_request_id IS NULL OR id != :exclude_loan_request_id); -- 貸出申請情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 件数 | - | - | - |
  | 検索条件 | 備品（内部ID） | ○ | 入力値．備品（内部ID） | - |
  | 検索条件 | 状態 | ○ | "承認済み","貸出中" | - |
  | 検索条件 | 開始日／返却予定日 | ○ | 入力値．開始日／入力値．返却予定日 | 両端を含む期間重複判定 |
  | 検索条件 | 内部ID（除外） | - | 入力値．除外する貸出申請（内部ID） | - |
