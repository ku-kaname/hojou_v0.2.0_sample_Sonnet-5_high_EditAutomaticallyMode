## ○処理詳細

### 1. 有効管理者ID一覧取得

- (1) USERテーブルから権限が「管理者」かつ有効なユーザーの内部IDを取得する。

  ```sql
  SELECT id
  FROM user
  WHERE
    role = :role              -- ユーザー情報．権限
    AND active_flag = :active_flag;  -- ユーザー情報．有効フラグ
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 検索条件 | 権限 | ○ | "管理者" | - |
  | 検索条件 | 有効フラグ | ○ | true | - |
