### 処理概要

#### 【目的】
- 内部IDをもとに貸出申請情報を1件取得する（F06・F07・F09・F12・ノーショー自動取消における対象存在確認・詳細表示に使用する）。

#### 【処理概略】
- 入力値の内部IDに一致する貸出申請情報をLOAN_REQUESTテーブルから取得する。
- 取得した貸出申請情報を返却する。

## ○処理詳細

### 1. 貸出申請情報取得

- (1) LOAN_REQUESTテーブルから取得する。

  ```sql
  SELECT
    id,                            -- 貸出申請情報．内部ID
    equipment_id,                  -- 貸出申請情報．備品（内部ID）
    applicant_user_id,             -- 貸出申請情報．申請者（ユーザー内部ID）
    start_date,                    -- 貸出申請情報．開始日
    due_date,                      -- 貸出申請情報．返却予定日
    purpose,                       -- 貸出申請情報．用途
    status,                        -- 貸出申請情報．状態
    reject_cancel_reason,          -- 貸出申請情報．却下・取消理由
    approved_rejected_by_user_id,  -- 貸出申請情報．承認・却下した管理者
    lent_by_user_id,                -- 貸出申請情報．貸出処理した管理者
    returned_by_user_id,            -- 貸出申請情報．返却処理した管理者
    cancelled_by_user_id,           -- 貸出申請情報．取消した者
    requested_at,                   -- 貸出申請情報．申請日時
    approved_rejected_at,           -- 貸出申請情報．承認却下日時
    lent_at,                         -- 貸出申請情報．貸出日時
    returned_at,                     -- 貸出申請情報．返却日時
    cancelled_at,                    -- 貸出申請情報．取消日時
    return_note                      -- 貸出申請情報．返却時状態メモ
  FROM loan_request
  WHERE
    id = :loan_request_id;  -- 貸出申請情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID～返却時状態メモ | - | - | 上記SELECT列の全項目 |
  | 検索条件 | 内部ID | ○ | 入力値．貸出申請（内部ID） | - |
