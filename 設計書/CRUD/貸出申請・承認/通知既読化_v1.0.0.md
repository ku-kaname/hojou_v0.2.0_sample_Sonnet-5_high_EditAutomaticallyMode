### 処理概要

#### 【目的】
- 通知を既読に更新する（F08）。

#### 【処理概略】
- 指定した通知（内部ID）に一致するレコードの既読フラグを既読に更新する。
- 更新後の通知情報を返却する。

## ○処理詳細

### 1. 通知情報更新

- (1) NOTIFICATIONテーブルを更新する。

  ```sql
  UPDATE notification
  SET
    read_flag = :read_flag  -- 通知情報．既読フラグ
  WHERE
    id = :notification_id;  -- 通知情報．内部ID
  ```
