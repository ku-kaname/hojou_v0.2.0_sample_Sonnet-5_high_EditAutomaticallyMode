### 処理概要

#### 【目的】
- 通知（内部ID）を指定して通知情報を1件取得する（F08の既読化処理において、対象の通知が存在するか・宛先が本人かを確認するために使用する）。

#### 【処理概略】
- 指定した通知（内部ID）に一致するレコードをNOTIFICATIONテーブルから取得する。
- 取得した通知情報を返却する。該当するレコードが存在しない場合はNoneを返却する。

## ○処理詳細

### 1. 通知情報取得

- (1) NOTIFICATIONテーブルから通知（内部ID）に一致するレコードを取得する。

  ```sql
  SELECT
    id, recipient_user_id, notification_type, loan_request_id,
    read_flag, created_at
  FROM notification
  WHERE
    id = :notification_id;  -- 通知情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID／宛先（ユーザー内部ID）／種別／関連申請（内部ID）／既読フラグ／作成日時 | - | - | 全列を取得 |
  | 検索条件 | 内部ID | ○ | 入力値．通知（内部ID） | - |
