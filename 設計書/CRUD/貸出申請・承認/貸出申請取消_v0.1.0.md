### 処理概要

#### 【目的】
- 貸出申請を取消に更新する（F06の申請者本人による取消、F12の管理者取消、ノーショー自動取消のいずれからも使用する汎用的な更新処理）。

#### 【処理概略】
- 状態を"取消"に更新し、取消した者・取消日時・取消理由を記録する。
  - F06（申請者取消）：取消した者＝申請者自身。理由は空でよい。
  - F12（管理者取消）：取消した者＝取消を行った管理者。理由は必須（呼出元のservices.pyが必須であることを確認する）。
  - ノーショー自動取消：取消した者＝None（自動取消のため。要件定義書/機能要件「取消した者...自動取消は空」）。理由はservices.py側でノーショーである旨の固定文言を設定する。
- 更新後の貸出申請情報を返却する。

## ○処理詳細

### 1. 貸出申請情報更新

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = :status,                           -- 貸出申請情報．状態
    cancelled_by_user_id = :cancelled_by_user_id, -- 貸出申請情報．取消した者
    cancelled_at = :now,                          -- 貸出申請情報．取消日時
    reject_cancel_reason = :reason                -- 貸出申請情報．却下・取消理由
  WHERE
    id = :loan_request_id;  -- 貸出申請情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | "取消" | - |
  | 更新内容 | 取消した者 | - | 入力値．取消した者（ユーザー内部ID） | 自動取消の場合はNULL |
  | 更新内容 | 取消日時 | ○ | 入力値．現在日時 | - |
  | 更新内容 | 却下・取消理由 | - | 入力値．取消理由 | 未指定の場合は空文字 |
  | 検索条件 | 内部ID | ○ | 入力値．貸出申請（内部ID） | - |
