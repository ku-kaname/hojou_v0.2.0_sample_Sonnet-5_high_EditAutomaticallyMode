| メソッド物理名 | create_notification |

### 処理概要

#### 【目的】
- 通知情報をデータベースへ新規登録する（F05の新規申請・F09の承認却下・F12の管理者取消・ノーショー自動取消の各処理から、通知対象者ごとに呼び出す）。

#### 【処理概略】
- 入力値をもとにNOTIFICATIONテーブルへレコードを登録する。既読フラグは未読固定とする。
- 登録した通知情報を返却する。

## ○処理詳細

### 1. 通知情報登録

- (1) NOTIFICATIONテーブルへ登録する。

  ```sql
  INSERT INTO notification (
    recipient_user_id,   -- 通知情報．宛先（ユーザー内部ID）
    notification_type,   -- 通知情報．種別
    loan_request_id,     -- 通知情報．関連申請（内部ID）
    read_flag,           -- 通知情報．既読フラグ
    created_at           -- 通知情報．作成日時
  ) VALUES (
    :recipient_user_id,
    :notification_type,
    :loan_request_id,
    :read_flag,
    :today
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 宛先（ユーザー内部ID） | ○ | 入力値．宛先（ユーザー内部ID） | - |
  | 登録内容 | 種別 | ○ | 入力値．種別 | - |
  | 登録内容 | 関連申請（内部ID） | ○ | 入力値．関連申請（内部ID） | - |
  | 登録内容 | 既読フラグ | ○ | false | - |
  | 登録内容 | 作成日時 | ○ | 入力値．現在日時 | - |
