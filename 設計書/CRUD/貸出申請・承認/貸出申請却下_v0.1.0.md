| メソッド物理名 | reject_loan_request |

### 処理概要

#### 【目的】
- 貸出申請を却下に更新する（F09）。

#### 【処理概略】
- 状態を"却下"に更新し、却下した管理者・承認却下日時・却下理由を記録する。
- 更新後の貸出申請情報を返却する。

## ○処理詳細

### 1. 貸出申請情報更新

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = :status,                                     -- 貸出申請情報．状態
    approved_rejected_by_user_id = :rejected_by_user_id,   -- 貸出申請情報．承認・却下した管理者
    approved_rejected_at = :now,                           -- 貸出申請情報．承認却下日時
    reject_cancel_reason = :reason                         -- 貸出申請情報．却下・取消理由
  WHERE
    id = :loan_request_id;  -- 貸出申請情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | "却下" | - |
  | 更新内容 | 承認・却下した管理者 | ○ | 入力値．却下した管理者（ユーザー内部ID） | - |
  | 更新内容 | 承認却下日時 | ○ | 入力値．現在日時 | - |
  | 更新内容 | 却下・取消理由 | ○ | 入力値．却下理由 | - |
  | 検索条件 | 内部ID | ○ | 入力値．貸出申請（内部ID） | - |
