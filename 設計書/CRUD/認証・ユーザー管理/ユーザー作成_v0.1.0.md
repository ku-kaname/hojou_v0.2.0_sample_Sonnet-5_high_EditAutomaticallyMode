| メソッド物理名 | create_user |

### 処理概要

#### 【目的】
- ユーザー情報をデータベースへ新規登録する（F16のユーザー登録、および初回管理者アカウントの起動時自動作成の両方で使用する）。

#### 【処理概略】
- 入力値をもとにUSERテーブルへレコードを登録する。有効フラグ・初回パスワード変更要否フラグ・トークン世代・連続認証失敗回数は固定の初期値を設定する。
- 登録したユーザー情報を返却する。

## ○処理詳細

### 1. ユーザー情報登録

- (1) USERテーブルへ登録する。

  ```sql
  INSERT INTO user (
    user_id,                        -- ユーザー情報．ユーザーID
    name,                           -- ユーザー情報．氏名
    department,                     -- ユーザー情報．所属
    hashed_password,                -- ユーザー情報．パスワードハッシュ
    role,                           -- ユーザー情報．ロール
    active_flag,                    -- ユーザー情報．有効フラグ
    password_change_required_flag, -- ユーザー情報．初回パスワード変更要否フラグ
    token_generation,               -- ユーザー情報．トークン世代
    login_failure_count,            -- ユーザー情報．連続認証失敗回数
    created_at,                     -- ユーザー情報．作成日時
    updated_at                      -- ユーザー情報．更新日時
  ) VALUES (
    :user_id,
    :name,
    :department,
    :hashed_password,
    :role,
    :active_flag,
    :password_change_required_flag,
    :token_generation,
    :login_failure_count,
    :today,

  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
