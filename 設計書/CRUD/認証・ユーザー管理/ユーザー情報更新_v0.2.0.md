| メソッド物理名 | update_user |

### 処理概要

#### 【目的】
- ユーザーの氏名・所属・ロールを更新する（F16のユーザー編集）。

#### 【処理概略】
- 入力値のユーザーIDをもとにUSERテーブルを検索し、氏名・所属・ロール・トークン世代を更新する。
- トークン世代の更新値は、呼出元（services.py）がロール変更の有無に応じて決定し、変更が無い場合は更新前の値を設定する（ロール変更時に世代を進める業務ルールへの対応。本メソッド自体は世代を進めるかどうかの判定を行わない）。
- 更新後のユーザー情報を返却する。

## ○処理詳細

### 1. ユーザー情報更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    name = :name,                         -- ユーザー情報．氏名
    department = :department,             -- ユーザー情報．所属
    role = :role,                         -- ユーザー情報．ロール
    token_generation = :token_generation, -- ユーザー情報．トークン世代
    updated_at = :today                   -- ユーザー情報．更新日時
  WHERE
    user_id = :user_id;  -- ユーザー情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 氏名 | ○ | 入力値．氏名 | - |
  | 更新内容 | 所属 | - | 入力値．所属 | 入力が無い場合は空文字 |
  | 更新内容 | ロール | ○ | 入力値．ロール | - |
  | 更新内容 | トークン世代 | ○ | 入力値．トークン世代 | - |
  | 更新内容 | 更新日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
