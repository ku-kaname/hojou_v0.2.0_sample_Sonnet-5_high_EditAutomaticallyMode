### 処理概要

#### 【目的】
- 有効な管理者ユーザーの件数を取得する（F16のユーザー無効化・ロール変更時における、最後の有効な管理者保護の判定に使用する。要件定義書/機能要件「最後の有効な管理者を、無効化またはロールを一般に変更することはできない」参照）。

#### 【処理概略】
- USERテーブルから、ロールが"管理者"かつ有効フラグがtrueのレコード件数を取得する。
- 取得した件数を返却する。

## ○処理詳細

### 1. 有効管理者数取得

- (1) USERテーブルから件数を取得する。

  ```sql
  SELECT
    COUNT(*)  -- ユーザー情報．件数
  FROM user
  WHERE
    role = :role               -- ユーザー情報．ロール
    AND active_flag = :active_flag;  -- ユーザー情報．有効フラグ
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 件数 | - | - | - |
  | 検索条件 | ロール | ○ | "管理者" | - |
  | 検索条件 | 有効フラグ | ○ | true | - |
