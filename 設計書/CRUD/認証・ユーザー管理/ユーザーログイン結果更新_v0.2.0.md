### 処理概要

#### 【目的】
- ログイン試行の結果（成功・失敗）に応じて、連続認証失敗回数・ロック解除日時を更新する（F01のログイン処理）。

#### 【処理概略】
- 入力値のユーザーIDをもとにUSERテーブルを検索し、連続認証失敗回数・ロック解除日時を更新する。
- 設定値は呼出元（services.py）が決定する（ログイン成功時は連続認証失敗回数を0・ロック解除日時を空に、失敗時は連続認証失敗回数をインクリメントした値・必要に応じてロック解除日時（現在時刻+15分）を設定する。要件定義書/機能要件「連続認証失敗回数」「ロック解除日時」参照）。

## ○処理詳細

### 1. ユーザーログイン結果更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    login_failure_count = :login_failure_count, -- ユーザー情報．連続認証失敗回数
    locked_until = :locked_until,                -- ユーザー情報．ロック解除日時
    updated_at = :today                          -- ユーザー情報．更新日時
  WHERE
    user_id = :user_id;  -- ユーザー情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 連続認証失敗回数 | ○ | 入力値．連続認証失敗回数 | - |
  | 更新内容 | ロック解除日時 | - | 入力値．ロック解除日時 | 入力が無い場合はNULLを設定する |
  | 更新内容 | 更新日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
