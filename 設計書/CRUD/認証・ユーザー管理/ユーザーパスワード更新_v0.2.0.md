### 処理概要

#### 【目的】
- ユーザーのパスワードハッシュを更新する（F02の本人によるパスワード変更、およびF16の管理者によるパスワード初期化の両方で使用する）。

#### 【処理概略】
- 入力値のユーザーIDをもとにUSERテーブルを検索し、パスワードハッシュ・初回パスワード変更要否フラグ・トークン世代を更新する。
- 初回パスワード変更要否フラグ・トークン世代の更新値は呼出元（services.py）が決定する（本人による変更の場合は変更要否フラグをfalseに、管理者による初期化の場合はtrueに設定する。いずれもトークン世代を進めた値を設定する。要件定義書/機能要件「トークンの失効」参照）。

## ○処理詳細

### 1. ユーザーパスワード更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    hashed_password = :hashed_password,                               -- ユーザー情報．パスワードハッシュ
    password_change_required_flag = :password_change_required_flag, -- ユーザー情報．初回パスワード変更要否フラグ
    token_generation = :token_generation,                             -- ユーザー情報．トークン世代
    updated_at = :today                                                -- ユーザー情報．更新日時
  WHERE
    user_id = :user_id;  -- ユーザー情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | パスワードハッシュ | ○ | 入力値．パスワードハッシュ | - |
  | 更新内容 | 初回パスワード変更要否フラグ | ○ | 入力値．初回パスワード変更要否フラグ | - |
  | 更新内容 | トークン世代 | ○ | 入力値．トークン世代 | - |
  | 更新内容 | 更新日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
