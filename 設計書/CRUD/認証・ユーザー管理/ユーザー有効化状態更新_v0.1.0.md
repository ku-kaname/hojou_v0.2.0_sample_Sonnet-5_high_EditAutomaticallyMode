| メソッド物理名 | update_user_active_flag |

### 処理概要

#### 【目的】
- ユーザーの有効フラグを更新する（F16のユーザー無効化・再有効化）。

#### 【処理概略】
- 入力値のユーザーIDをもとにUSERテーブルを検索し、有効フラグ・トークン世代を更新する。
- トークン世代の更新値は呼出元（services.py）が決定する（無効化時は世代を進めた値、再有効化時は更新前の値を設定する。要件定義書/機能要件「トークンの失効」参照）。

## ○処理詳細

### 1. ユーザー有効化状態更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    active_flag = :active_flag,           -- ユーザー情報．有効フラグ
    token_generation = :token_generation, -- ユーザー情報．トークン世代
    updated_at = :today                   -- ユーザー情報．更新日時
  WHERE
    user_id = :user_id;  -- ユーザー情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 有効フラグ | ○ | 入力値．有効フラグ | - |
  | 更新内容 | トークン世代 | ○ | 入力値．トークン世代 | - |
  | 更新内容 | 更新日時 | ○ | 入力値．現在日時 | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
