### 処理概要

#### 【目的】
- 登録されている全てのユーザー情報を取得する（F16のユーザー一覧表示用）。

#### 【処理概略】
- USERテーブルから、有効フラグに関わらず全件取得する（無効化済みユーザーも一覧に含める。表示上の絞り込みは画面側の責務とする）。
- 取得したユーザー情報のリストを、ユーザーIDの昇順で返却する。

## ○処理詳細

### 1. 全ユーザー情報取得

- (1) USERテーブルから全件取得する。

  ```sql
  SELECT
    id,                             -- ユーザー情報．内部ID
    user_id,                        -- ユーザー情報．ユーザーID
    name,                           -- ユーザー情報．氏名
    department,                     -- ユーザー情報．所属
    hashed_password,                -- ユーザー情報．パスワードハッシュ
    role,                           -- ユーザー情報．ロール
    active_flag,                    -- ユーザー情報．有効フラグ
    password_change_required_flag, -- ユーザー情報．初回パスワード変更要否フラグ
    token_generation,               -- ユーザー情報．トークン世代
    login_failure_count,            -- ユーザー情報．連続認証失敗回数
    locked_until,                   -- ユーザー情報．ロック解除日時
    created_at,                     -- ユーザー情報．作成日時
    updated_at                      -- ユーザー情報．更新日時
  FROM user
  ORDER BY user_id ASC;  -- ユーザー情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID～更新日時 | - | - | 上記SELECT列の全項目 |
  | 検索条件 | - | - | - | - |
  | ソート条件 | ユーザーID | ○ | 昇順 | - |
