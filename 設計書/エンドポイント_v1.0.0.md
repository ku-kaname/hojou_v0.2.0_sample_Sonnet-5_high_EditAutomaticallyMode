## 機能ごとのエンドポイント

|機能|HTTPメソッド|エンドポイント|備考|
|---|---|---|---|
| ヘルスチェック | GET | /health-check | 認証不要 |
| トークン発行（ログイン） | POST | /token | 認証不要。フォームデータ（OAuth2PasswordRequestForm）。F01 |
| ログアウト | POST | /logout | 要Bearer認証。トークン世代を+1。F01 |
| 自分の情報取得 | GET | /users/me | 要Bearer認証。ログイン状態復元・画面表示用（F01の補助） |
| パスワード変更 | PATCH | /users/me/password | 要Bearer認証。F02 |
| ユーザー一覧取得 | GET | /users | 要Bearer認証（管理者のみ）。F16 |
| ユーザー登録 | POST | /users | 要Bearer認証（管理者のみ）。F16 |
| ユーザー詳細取得 | GET | /users/{user_id} | 要Bearer認証（管理者のみ）。F16 |
| ユーザー編集 | PUT | /users/{user_id} | 要Bearer認証（管理者のみ）。氏名・所属・ロールを変更。F16 |
| ユーザー無効化 | PATCH | /users/{user_id}/deactivate | 要Bearer認証（管理者のみ）。F16 |
| ユーザー再有効化 | PATCH | /users/{user_id}/activate | 要Bearer認証（管理者のみ）。F16 |
| パスワード初期化 | PATCH | /users/{user_id}/reset-password | 要Bearer認証（管理者のみ）。F16 |
| 備品検索・一覧取得 | GET | /equipment | 要Bearer認証。F03 |
| 備品詳細取得 | GET | /equipment/{equipment_id} | 要Bearer認証。F03 |
| 備品予約状況確認 | GET | /equipment/{equipment_id}/reservations | 要Bearer認証。F04 |
| 備品登録 | POST | /equipment | 要Bearer認証（管理者のみ）。F14 |
| 備品編集 | PUT | /equipment/{equipment_id} | 要Bearer認証（管理者のみ）。F14 |
| 備品無効化 | PATCH | /equipment/{equipment_id}/deactivate | 要Bearer認証（管理者のみ）。F14 |
| 備品再有効化 | PATCH | /equipment/{equipment_id}/activate | 要Bearer認証（管理者のみ）。F14 |
| 備品CSV一括登録 | POST | /equipment/bulk-import | 要Bearer認証（管理者のみ）。multipart/form-data。F15 |
| 貸出申請 | POST | /loan-requests | 要Bearer認証。F05 |
| 貸出申請一覧取得 | GET | /loan-requests | 要Bearer認証。クエリパラメータで自分の申請（F07）／全申請（F09、管理者のみ）／期限超過（F13、管理者のみ）を絞り込み |
| 貸出申請詳細取得 | GET | /loan-requests/{loan_request_id} | 要Bearer認証。F07/F09共通 |
| 貸出申請取消 | PATCH | /loan-requests/{loan_request_id}/cancel | 要Bearer認証。申請者本人のみ。F06 |
| 貸出申請承認 | PATCH | /loan-requests/{loan_request_id}/approve | 要Bearer認証（管理者のみ）。F09 |
| 貸出申請却下 | PATCH | /loan-requests/{loan_request_id}/reject | 要Bearer認証（管理者のみ）。F09 |
| 貸出申請管理者取消 | PATCH | /loan-requests/{loan_request_id}/admin-cancel | 要Bearer認証（管理者のみ）。F12 |
| 貸出処理 | PATCH | /loan-requests/{loan_request_id}/lend | 要Bearer認証（管理者のみ）。F10 |
| 返却処理 | PATCH | /loan-requests/{loan_request_id}/return | 要Bearer認証（管理者のみ）。F11 |
| 貸出履歴CSV出力 | GET | /loan-requests/export | 要Bearer認証（管理者のみ）。F17 |
| 通知一覧取得 | GET | /notifications | 要Bearer認証。F08 |
| 通知既読化 | PATCH | /notifications/{notification_id}/read | 要Bearer認証。F08 |
